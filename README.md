## 🚀 Featured Projects

### 🛡️ [GuardianX](https://github.com/rushabh-borkar/GuardianX)
AI-powered emergency detection from multi-camera feeds. Concurrent YOLOv8 inference classifies incidents (fire, violence, hazards), a FastAPI backend pushes alerts over WebSockets, and a React + Leaflet dashboard shows them live on a map.

### 🤝 [MentorMatch-AI](https://github.com/rushabh-borkar/MentorMatch-AI) · *In progress*
Mentorship platform with role-based access (student, mentor, admin) via Supabase Auth. Multi-factor scoring across skills, career paths, and knowledge gaps, with a human-readable explanation for every match.

### 🕸️ [GNN-based Fraud Detection](https://github.com/rushabh-borkar/GNN-based-fraud-detection) · [Fraud Detection ML](https://github.com/rushabh-borkar/fraud-detection-ml)
Graph neural networks that model transaction topology to uncover fraud rings. Handles extreme class imbalance (>99:1) using PR-AUC, F-Beta weighting, and strict temporal splits to prevent look-ahead leakage.

![PyTorch Geometric](https://img.shields.io/badge/PyTorch_Geometric-EE4C2C?style=flat-square&logo=pytorch&logoColor=white)
![scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)

### 🏭 [Predictive Maintenance](https://github.com/rushabh-borkar/Predictive-Maintenance-Machine-Failure-Prediction)
Predicts machine failures from sensor data (rotational speed, torque, tool wear, heat) using multivariate classification.

### ☄️ [Asteroid Hazard Classifier](https://github.com/rushabh-borkar/Near-Earth-Asteroid-Hazard-Classification-using-Logistic-Regression)
Logistic regression built from scratch in NumPy, with custom batch gradient descent and precision-recall threshold tuning on NASA data.
