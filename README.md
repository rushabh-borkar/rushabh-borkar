## Featured Projects

- **[GuardianX](https://github.com/rushabh-borkar/GuardianX)**: AI emergency detection from multi-camera feeds using YOLOv8 and OpenCV, with a FastAPI backend, WebSocket alerts, and a live React map dashboard.
- **[MentorMatch-AI](https://github.com/rushabh-borkar/MentorMatch-AI)**: Mentorship matching platform with role-based access (Supabase Auth) and human-readable explanations for every match. *(In progress)*
- **[GNN-based Fraud Detection](https://github.com/rushabh-borkar/GNN-based-fraud-detection)** and **[Fraud Detection ML](https://github.com/rushabh-borkar/fraud-detection-ml)**: Graph neural networks for detecting fraud rings, with temporal splits to prevent leakage and PR-AUC for extreme class imbalance.
- **[Predictive Maintenance](https://github.com/rushabh-borkar/Predictive-Maintenance-Machine-Failure-Prediction)**: Predicts machine failures from sensor data (speed, torque, tool wear, heat).
- **[Asteroid Hazard Classifier](https://github.com/rushabh-borkar/Near-Earth-Asteroid-Hazard-Classification-using-Logistic-Regression)**: Logistic regression with gradient descent built from scratch in NumPy.
